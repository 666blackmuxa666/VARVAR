# VARVAR — правила (коротко; повна версія — `_team/rules-full.md`)

Каса (POS), 3 Telegram-боти, меню гостя, сайт-візитка, доставка, склад, ЗП, броні. Платформа на багато закладів (`/v/<id>/…`). Інтерфейс, коментарі й відповіді — **українською, коротко**.

## Де що
- **Спершу `graphify-out/` або `_team/map.md`**, потім `grep -n` + `sed -n` у потрібних рядках. Файли цілком не читати.
- Задачі й план — кабінет → «🗺 План» (KV `atom:plan`): `node tools/plan.mjs next|take|done|add|draft`, ⭐ першими. `_team/board.md` — лише «На злиття» і «Звіти».
- Агент команди: регламент (гілка, звіт ≤10 рядків, без деплою) — `_team/rules-full.md`.
- Паспорт розділу — `_team/<розділ>.md` (таблиця розділів — `_team/rules-full.md`). Мультизаклад — `_team/platform.md`. Тести — `_team/qa.md`.
- Сервер: Worker `worker/src/`, база — один DO `Store` (`env.DB` як KV). «Прочитав → змінив → записав» — лише під `L(env, keys, fn)`.
- Каса: `js/pos/NN-*.js` → одна функція (не ES-модулі), збірка `sh tools/build-pos.sh`. `ops.js`/`bot.js` — вітрини, код у `ops-*`/`bot-*`.

## Перевірка й викладання
- Тести: `sh tools/test.sh --quiet` (вибірково `--api-only` / `--ui-only --views=…`). Лише `worker-test`; конфіг `worker` не запускати; у `.varvar-test` вручну не rsync.
- Нова op або зміна поведінки — свій крок у `tools/selftest.mjs`.
- Деплой — тільки `sh tools/deploy.sh`, керівник робить сам без питань.
- UI перевіряти текстом (`read_page`); скриншот — лише для показу. Власнику показувати картинки файлом (SendUserFile), він з телефона.

## Заборони
- Не публікувати `printer/varvar-print.config.json`. Секрети — лише `wrangler secret put`.
- Не створювати тестових працівників/замовлень на робочому сервері; не спамити групу Telegram.
- Стан закладу — не в глобальних змінних модулів (`cur()`, `siteLink()`). Зміна формату даних — нова міграція в `migrate.js`.
- Фіскальні тести — лише atom-demo або mock. Не послаблювати ліміти безпеки. Без персональних даних у репо.
- Не комітити `.manus/`, `.work/`, `outputs/`, `PRODUCT.md`.
- Паритет каса ⇄ бот персоналу. Економити запити Cloudflare, без опитування (polling).

## Стиль
Темна тема, змінні `--card/--accent…`, `.card` з `h3`, `.kv`, `.btn sm`; галочки — квадрат, налаштування — перемикачі (`.kv > input`, `.sw`). Текст переноситься, не вилазить (375/880/1280). Підписи з емодзі.
