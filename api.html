API для партнерів

Версія v1. Для агрегаторів доставки, сайтів, програм лояльності й бухгалтерії. Ключ видає власник закладу в кабінеті ATOM → ⚙️ Заклад → 🔌 API.

Основи

Адреса: https://posatom.online/v/<заклад>/api/v1/ — ідентифікатор закладу показано в кабінеті поруч із ключем.

Ключ передається в заголовку Authorization: Bearer atk_… (або X-Api-Key). Ключ має права: menu, orders, sales, stock. Тримайте його лише на своєму сервері, не в браузері чи мобільному застосунку.

Ліміт: 60 запитів на хвилину на ключ (далі 429). Опитувати нас не потрібно: про зміни статусів, меню й стоп-листа ми самі повідомляємо через webhook.

Формат: JSON, UTF-8, суми — у гривнях (цілі), час — ISO 8601.

curl https://posatom.online/v/demo-cafe/api/v1/ping \
  -H "Authorization: Bearer atk_1a2b3c4d_…"

Відповідь: { "ok": true, "id": "3f9a1c0b7e", "ext_id": "GL-100245", "no": "Д-12", "total": 540, "status": "new", "prep_min": 30 }. Ціни рахує заклад за своїм меню; страви, яких немає або в стоп-листі, пропускаються.

Помилки: closed_for_orders, closed_now, below_minimum, no_valid_items, customer, address, excise (алкоголь не продається зараз).

Webhook

Якщо для ключа вказано адресу webhook (лише https), ATOM сам надсилає POST, коли щось змінилось. Тип події — у полі event і заголовку X-Atom-Event.

eventПравоКоли
order.statusordersЗмінився статус вашого замовлення (зазвичай за 1–2 хв)
stop.changedmenuСтрава потрапила в стоп-лист або повернулась у продаж (за ~30 с)
menu.changedmenuЗмінились ціни, страви чи категорії — заберіть menu з новим etag

order.status

{ "event": "order.status", "venue": "demo-cafe",
  "order": { "id": "3f9a1c0b7e", "ext_id": "GL-100245", "status": "road", "no": "Д-12", "courier": "Андрій" },
  "sent_at": "2026-10-21T15:04:05.000Z" }

stop.changed

{ "event": "stop.changed", "venue": "demo-cafe", "etag": "\"m4f1c…\"",
  "stopped": ["carbonara"],          // щойно в стоп-листі
  "available": ["lemonade"],          // знову в продажу
  "stop_list": ["carbonara", "tiramisu"],  // повний стоп-лист зараз
  "sent_at": "2026-10-21T15:04:05.000Z" }

menu.changed

{ "event": "menu.changed", "venue": "demo-cafe", "etag": "\"m9a2d…\"", "sent_at": "…" }

Кілька змін поспіль приходять одним сповіщенням. Перше сповіщення приходить лише після першої зміни: на старті заберіть меню запитом GET menu.

Відповідайте кодом 2xx. Якщо ні — повтор через 1, 5, 30 і 120 хвилин. Тестове сповіщення з кабінету має "event": "ping".

Перевірка підпису

Заголовок X-Atom-Signature — HMAC-SHA256 тіла запиту секретом whs_… (видається разом із ключем), у hex.

// Node.js
const crypto = require('crypto');
const ok = crypto.timingSafeEqual(
  Buffer.from(req.headers['x-atom-signature'], 'hex'),
  crypto.createHmac('sha256', process.env.ATOM_WHS).update(rawBody).digest());

Коди відповідей

200 — успіх · 304 — меню не змінилось · 400 — помилка в даних (поле error) · 401 — немає або невірний ключ · 403 — у ключа немає права · 404 — не знайдено · 429 — ліміт запитів.

Питання щодо інтеграції — підтримка ATOM у Telegram (посилання на головній сторінці).
