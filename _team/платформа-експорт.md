# 📤 Експорт для бухгалтера
- Сервер: `worker/src/acct.js` `acctExport(env, from, to)` → `{sections:[{id,title,head,rows}]}`: sales (по днях), checks, pay (готівка/карта/онлайн/чайові), inv (накладні складу), off + offIng (списання), exp (витрати з каси), zp (ЗП по місяцях). Лише читання; op `acctExport` — тільки адмін (`pos.js`).
- Каса: 📊 Звіти → «📤 Бухгалтеру» (період — обраний у звітах): CSV (UTF-8 BOM, `;`) або друк/PDF. Кабінет власника: ⚙️ Заклад → «📤 Експорт для бухгалтера» (довільні дати).
- Тест: «📤 експорт для бухгалтера» у selftest.

# 📅 Податковий календар
- `worker/src/tax.js`: ключ бази `tax` = `{kind: fop1|fop2|fop3|tov, pdv, on, lead, rates, done}`. `taxEvents` генерує строки (вихідний → наступний робочий день), `taxAmount` — орієнтовна сума (ФОП3: % від виручки кварталу; ЄСВ від мін. ЗП; ТОВ: від фонду ЗП). Ставки з `rates` (дефолти `RATES` — звірити щороку).
- Нагадування: `taxDaily` у `cron()` (після 9:00 Київ, раз на добу): за `lead` днів, у день, на наступний день після строку. Особистий чат власника (`digchat`) — із сумами; без нього — у робочу групу без сум. Посилання — кабінет платника (cabinet.tax.gov.ua). КЕП/рахунки не чіпаємо.
- Ops (адмін): `taxGet`, `taxSet`, `taxDone`. UI: каса ⚙️ «📅 Податковий календар»; кабінет власника ⚙️ Заклад.
- Дати/суми орієнтовні — скрізь «звірте з бухгалтером».

# 🔐 PIN адміністратора ≥6 цифр і ключ друку в заголовку
- `ops.js` `pinRule(role)`: admin — 6–8 цифр, решта — 4. Діє в `_addStaff`, `updateStaff` (підвищення до адміна — лише з новим PIN), реєстрації (каса/бот). Старі 4-значні PIN адмінів працюють, доки їх не змінять. Вхід (каса/бот) приймає 4–8 цифр.
- Програма друку (`printer/varvar-print.ps1`) шле ключ у заголовку `X-Print-Key`, без `?key=` і без ключа в тілі. Сервер (`print.js`) досі приймає й старий `?key=` — прибрати, коли всі каси оновлять програму.

# 🚨 Тривога «продаж нижче собівартості»
- `stock.js` `lossList(menu, cards, im)` — позиції (і варіанти) з техкартою, де вартість > ціни меню. У `costReport` → `loss`; у касі «Склад → Звіт» червона картка. `lossDaily` (cron, після 10:00 Київ): сповіщення в робочу групу лише коли набір змінився (`lossSig`).
