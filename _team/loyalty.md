# 🎁 Гості й акції (лояльність)

## Що робить
Постійні клієнти за телефоном: **рівні** (Новий / Постійний / VIP / Персонал…) зі знижкою % або власним кешбеком; **акції-правила** (% на категорію/страву, щасливі години, N-та в подарунок, від суми — знижка або подарунок, день народження ±N днів) з умовами «де» (зал / з собою / доставка), періодом дії й увімк/вимк. Знижки рахує **лише сервер** — у залі, в доставці з каси, на сайті `?go` (кошик і замовлення), у чеку — назвою акції. Картка клієнта (рівень, бонуси, ДН, нотатка, історія), список з фільтрами, звіт «скільки дали знижок».

## Файли
- `worker/src/promo.js` — уся логіка:
  - `getLoy` (ключ `loy`, типові `LOY_DEF`), `cliLevel(cfg, cli)` — ручний `cli.lvl` або найвищий досягнутий (візити **або** сума; `man:1` — лише вручну).
  - `promoCalc(cfg, {items, kind, cli, ph, now, manual, catOf})` — **чиста** функція → `{lines:[{k,n,amt,info?}], sum, lvl, lvn, cash, nth}`. Стеля `cfg.max`% від суми страв (рядок «🛵 Доставка» не враховується).
  - `promoFill(env, bill, ctx)` — ставить/знімає `bill.promo` у пам'яті (зберігає той, хто викликав); `promoFillMany` — для списку столів зі спільним кешем меню/налаштувань.
  - `promoClose(env, bill, sum)` — після закриття: лічильники «N-та в подарунок» (`cli.nth`) та історія `cli.h` (≤30).
  - `promoQuote` — `POST /api/promo` для кошика `?go` (ціни з меню, як у `goOrder`).
  - Клієнти: `cliList(q, f)` (f: all | id рівня | bd ±7 днів | sleep 30+ днів | bal), `cliCard`, `cliEdit` (рівень — лише адмін).
  - `loyReport(from, to)` — з `closed:<day>` (поле `promo`).
  - `loyApi` — op каси `loy*`; `loyBotText` / `loyBotCb` — бот персоналу.
- `js/pos/75-loyalty.js` — каса: «⚙️ Налаштування → 🎁 Лояльність» (`loyHTML`: 👥 Клієнти / 🏅 Рівні / 🎯 Акції / 📊 Звіт), `loyLvEdit`, `loyRuleEdit`, `loyCliCard` (картка клієнта), свій обробник кліків `loy*`.

## Точкові правки в чужих файлах (позначені коментарем 🎁)
- `ops.js`: `payable` віднімає `b.promo.sum`; `_closeTable` — `promoFill` на початку, `cliClose(..., bill.promo?.cash)`, `promoClose`, у `closed:` пишуться `promo` (рядки з сумою), `promoSum`, `gross`; `precheck` — `promoFill`; `reprintClosed` — акції й бонуси в повторному чеку.
- `print.js`: у чеку рядки акцій і бонусів/сертифіката; «ДО СПЛАТИ/СПЛАЧЕНО» = `payable(bill)` (раніше бонуси в паперовому чеку не віднімались).
- `delivery.js`: `cliClose` — 6-й параметр кешбек рівня; `goOrder` — `promoFill` після `bill.log`, рядки акцій у повідомленні персоналу, `sum`/`promo` у відповіді гостю.
- `pos.js`: роутер `loy*` → `loyApi`; `state` — `promoFillMany` (щоб `pay2` і рядки були свіжі).
- `index.js`: `/api/promo` (+ в `IN_STORE`); `/api/status` — `promoFill`, гостю `bill.promo`.
- `bot.js`: кнопка «🎁 Гості й акції», текст `клієнт 050…` / `клієнт Іван` / `акції`, колбеки `lcl: llv: lro:`; `billSum`/`tableView`/`closeAsk` показують акції.
- `10-hall.js`: рядки акцій у рахунку (адмін × — «без акцій» на столі, ↺ — повернути), чип рівня в заголовку (тап → картка). Рядок «Знижка N%» тепер показує саму знижку (раніше `total − pay2`, що з бонусами/акціями було б неправильно).
- `20-delivery.js` (`cliT`): рівень, ДН, нотатка, кешбек рівня, кнопка «👤 Картка клієнта».
- `70-settings.js`: вкладка `loy`.
- `js/app.js` (`?go`): `goPromo()` → `/api/promo` при відкритті форми, зміні типу/телефону; рядки акцій у підсумку, `goTotal` з акціями.

## Ключі бази
- `loy` → `{ on, max, levels:[{id, name, e, n, sum, pct, cash, man?}], rules:[{id, type, name, on, pct, where[], cats[], dishes[], d1, d2, days[], from, to, n, min, gift, bdays}] }` (під замком `loy`).
- `cli:<380…>` + `{ lvl?, bd 'MM-DD', note, nth:{ruleId: шт}, h:[{ts, t: hall|pick|del, sum, pr?}] }` (через `cliTouch`, під замком `cli:<тел>`).
- `bill:<t>` + `promo` (знімок для показу; **на закритті рахується наново**), `promoOff` (адмін вимкнув акції на столі).
- `closed:<day>` + `promo:[{k, n, amt}]`, `promoSum`, `gross`.

## API
- Каса (`/api/pos`): `loyGet` (усі, крім кухаря/кур'єра), `loyCli {q, f}`, `loyCliGet {phone}`, `loyCliSet {phone, f:{name, bd, note, lvl}}` (lvl — адмін), адмін: `loySet {on | max}`, `loyLevel {lv | del}`, `loyRule {rule | del}`, `loyRuleOn {id, on}`, `loyOff {t, off}`, `loyRep {from, to}`.
- Сайт: `POST /api/promo {kind, phone, items}` → `{lines, sum, lvl}` (лише показ; `/api/go` рахує сам).

## Telegram (бот персоналу) — паритет
- «🎁 Гості й акції» або `акції` — рівні, акції; адмін — кнопки ⛔/✅ (`lro:`).
- `клієнт 0501234567` / `клієнт Іван` — картка (рівень, візити, бонуси, ДН, нотатка, історія); адмін — кнопки рівня (`llv:`), список збігів (`lcl:`).
- Створення/редагування правил і рівнів — лише в касі (форми з багатьма полями).

## Правила складання
- Рівень і **ручна** знижка офіціанта не складаються: якщо `bill.disc ≥ pct рівня` — рівень не діє (видно лише одну).
- Акції-правила складаються між собою і з рівнем, але разом ≤ `max`% (типово 50) суми страв.
- Бонуси (`bill.bonus`) і сертифікат — окремо, як і раніше.
- «N-та в подарунок»: з телефоном — накопичувально через візити (`cli.nth`), без телефону — в межах чека; дарується найдешевша одиниця з тих, що підпадають.
- «Від суми — подарунок»: якщо страва-подарунок уже в рахунку — знижка на 1 шт.; інакше рядок «додайте в рахунок» без суми.
- Час/дні — київські; щасливі години через північ працюють (22:00–02:00).

## Тонкі місця
- `bill.promo` у базі може бути застарілим між діями — довіряємо лише `promoFill` (state, пречек, закриття, бот, сайт).
- Z-звіт і `day:.disc` — лише ручні знижки (як було); знижки акцій — у звіті «🎁 → 📊 Звіт» (`loyRep`).
- Видалення/повернення закритого чека не відкатує історію клієнта й лічильники `nth` (як і кешбек раніше).
- Сайт `?go` на localhost ходить на `:8787` (жорстко в конфігу) — кошик з акціями перевіряти на спільному worker-test.

## Як перевіряти (worker-test)
1. `rsync -a worker/src/ ../.varvar-test/worker/src/`, `worker-test` + `site`.
2. Каса → ⚙️ → 🎁 Лояльність → 🎯 Акції → «Щасливі години» на поточну годину → стіл: рядок «−N», сума зменшилась.
3. Клієнт з рівнем (картка → 🏅 Рівень) → на столі «🎁 Гість» → телефон → рядок рівня; ручна знижка більша — рівень зникає.
4. Закрити → «🧾 Чеки» / 📊 Звіт лояльності; картка клієнта — історія.
5. `node tools/selftest.mjs` — секція «🎁 Лояльність» (рівень → автознижка, без складання, щасливі години, кошик сайту, `/api/go`, звіт, права).
