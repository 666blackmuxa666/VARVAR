# 🔌 API для партнерів (v1)

Для агрегаторів (Glovo, Bolt), сайтів, лояльності, бухгалтерії. Документація для партнерів — `api.html` (posatom.online/api).

## Як влаштовано
- Код — `worker/src/api-v1.js`; маршрут `/api/v1/*` у `index.js` (виконується в Store закладу); на posatom.online — `/v/<заклад>/api/v1/…`.
- **Ключ** `atk_<id8>_<секрет32>`, у базі лише sha256 — ключ `apikeys` [{id, name, sc[], h, at, by, last, hook?, hs?}]. До 10 ключів. Права: `menu`, `orders`, `sales`, `stock`.
- **Ліміт** 60/хв на ключ (`apirl:<id>`). «Востаннє використано» пишеться не частіше разу на годину.
- **Замовлення** → той самий `goOrder` (delivery.js), що й сайт `?go`: прапорець `_api` знімає лише ліміт пристрою гостя (у `/api/go` гостя `_api` видаляється). `prepaid` → `_paid` (як онлайн-оплата). Ідемпотентність — `apiidem:<key>:<ext_id>` (2 доби), власник замовлення — `apiord:<oid>`.
- **Webhook** статусів: `apiwatch` [{id, k, ext, last, tries, next}] → `apiTick` у `cron()` (site.js) щохвилини, поки є активні; повтори 1/5/30/120 хв, потім одне повідомлення в групу на добу. Підпис `X-Atom-Signature` = HMAC-SHA256(hs, тіло). Будильник одразу після замовлення — `env.WAKE` (store.js).
- **Кабінет:** ⚙️ Заклад → 🔌 API (`owner-venue.js`): ключі, права, webhook, тест, відкликання. Ops каси `apiKeys/apiKeyNew/apiKeyDel/apiKeyHook/apiHookTest` — лише справжній адмін (не «права галочкою»), не демо-гість.
- **Журнал:** створення/відкликання ключів і кожне замовлення з API — `audit` (ledger.js).
- **Тести:** selftest «🔌 API партнерів (v1)».
- Паритет з ботом: керування ключами — лише кабінет власника (інструмент власника, як підписка й боти).
