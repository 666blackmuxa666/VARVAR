# 👷 Персонал і зарплата

## Що робить
Графік змін (план і фактичний прихід), підтвердження змін адміном, обміни змінами між колегами, нарахування ЗП (ставка за зміну + % від бази + бонуси за план дня/місяця + оплата кур'єру за доставку + премії − штрафи), видача авансів/виплат із каси або картки (рух грошей), особистий кабінет працівника.

## Файли
- `js/pos/85-team.js` — розділ каси «Персонал».
  - `loadPay` → `zpGrid` за місяць `S.zpM`; `teamHTML/payHTML` → сітка графіка + відомість;
  - `zpCell` → клік по клітинці: майбутнє — план «+»/час, минуле — ✅/прибрати; `zpPend` → черга «чекає підтвердження» (у т.ч. «підтвердити все»);
  - `zpSet` → умови оплати працівника (`zpStaff`); `zpOpN` → премія/штраф/аванс/виплата (`zpOp`);
  - `zpMy` → кабінет (мої зміни, нараховано, обміни, запит обміну `zpSwap`); кліки `zpIn/zpOut` (почати/закінчити зміну), `zpCopy` (копія плану тижня), `zpAddP/zpDelP` (людина в графіку місяця), `zpSw` (крок обміну), `zpConf`.
- `worker/src/pay.js` — логіка й `payApi`.
  - `shiftIn/shiftOut` (прихід/вихід, запізнення від плану), `attConfirm` (o/f/n), `attToggle` (адмін ставить/знімає), `closeStale` (раз на добу закриває забуті зміни, `attchk`);
  - `planSet`, `planCopyWeek`; `payOp/payOpDel` (операції + рух грошей `mov:`), `setStaffPay`;
  - `payroll(m)` → відомість (`rows`, `revenue`, `fund`, `fundPct`), `myPay` (кабінет), `swapAsk/swapStep`, `payText` (текст для бота).

## Ключі бази
- `att:<YYYY-MM>` → `{ день: { імʼя: {in,out,ok:0|1|-1,late,auto,by} } }`
- `plan:<YYYY-MM>` → `{ день: { імʼя: 'HH:MM' | '+' } }`
- `pay:<YYYY-MM>` → `[{id,ts,day,n,t:'bonus'|'fine'|'adv'|'paid',sum,src,mov,note,by,del}]`
- `mov:<день>` → рух грошей (тип `salc` готівка / `salk` картка) — спільний із Касою
- `swaps` → `[{id,from,to,day,time,st:'ask'|'agreed'|'done'|'no',by}]` (останні 100)
- `gridx:<YYYY-MM>` → `{add:[],hide:[]}`; `seen:<YYYY-MM>`; `attchk` → день останнього `closeStale`
- `staff` → працівники з `pay:{rate,pct,base:'all'|'own'|'kitchen',dayRev,dayBonus,monRev,monBonus,dlv}`

## API каси (`/^zp[A-Z]/` → `payApi`)
- Усім (`ALL`, у т.ч. кухар і кур'єр): `zpIn, zpOut, zpMy, zpSwap, zpSwapStep, zpPeople`.
- Лише адмін: `zpGrid, zpAtt, zpPlan, zpPlanCopy, zpOp, zpOpDel, zpGridSet, zpStaff`.
- `zpSwapStep`: `agree` — лише той, кого просили; `ok` — адмін; `no` — адмін або учасник. Параметр `m` = `YYYY-MM`.

## Telegram (бот персоналу)
- `👷 Зарплата` / `зарплата` → `payText` + кнопки `zpb:<staffId>` → `zpbs:<staffId>:cash|card` (видати все «до виплати»).
- Текст (адмін): `премія Гріша 300 за суботу`, `штраф …`, `аванс Назар 500 з картки`.
- `зміна` / `/shift` — почати/закінчити (за Telegram first_name = імʼя в персоналі).
- З групи: `atk:<день>:<staffId>:o|f|n` (підтвердити зміну), `swk:<swapId>:ok|no` (обмін). Усі — лише адмін.

## Зв'язки
- Звіти (`reportRange`) → виручка для % і бонусів; кухня — за `groupOf` категорії.
- Каса-гроші: аванс/виплата → `mov:`; видалення операції → `delMove/restoreMove`. Чайові — `tipBalances` (лише показ).
- Доставка: `getGoCfg().cpay` — тариф кур'єра; `zpOut` кур'єра → `courShiftEnd`.
- Стрічка подій (`logEvent/editEv`), `notify` у робочу групу.

## Тонкі місця
- Усі записи `att/plan/pay/swaps/gridx/staff` — під `L()` з відповідним ключем.
- `payOp`: `mov:` і `pay:` пишуться під двома окремими замками — збій між ними = гроші пішли без операції ЗП.
- `zpbs` у боті: `due` рахується поза замком → подвійне натискання видасть двічі.
- `planCopyWeek` — послідовні `planSet` без загального замка, перезаписує цільовий тиждень.
- Бот визначає працівника за `first_name` Telegram — збіг імен ненадійний.
- Години 00–02 належать попередньому робочому дню (`at()`), часовий пояс Київ (`TZ`).

## Як перевіряти (worker-test)
1. Створити тестових працівників (кухар, кур'єр) на тестовому сервері, задати ставку/%.
2. Під кухарем: «🟢 Почати зміну» → в адміна з'являється «чекає» → підтвердити → ✅ у сітці.
3. Аванс з каси → рядок у Касі (рух грошей) і в відомості; видалити → гроші повертаються.
4. Обмін: A просить B → B погоджується в кабінеті → адмін підтверджує → план переставлено.
5. Перевірити 375 / 880 / 1280 — сітка скролиться, текст не вилазить.
