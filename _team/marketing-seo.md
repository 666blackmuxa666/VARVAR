# 📣 SEO-статті ATOM — чернетки (не опубліковано)

Правила: українською, без вигаданих цифр; усе, що позначено 🔎, — звірити з офіційним джерелом перед публікацією. Кожна стаття закінчується блоком «Спробувати касу без реєстрації» (демо) і не називає конкурентів у порівняннях.

## 1. Фудкост: як порахувати собівартість страви і не втратити гроші
**Запит:** «фудкост», «як рахувати собівартість страви», «техкарта».
**План:**
1. Що таке фудкост: собівартість продуктів у страві ÷ ціна продажу без ПДВ. Приклад на умовному бургері (числа ілюстративні, підписати «приклад»).
2. Техкарта: склад, вихід у грамах, відходи (чистка/термообробка).
3. Типові помилки: ціна закупівлі «з голови», забули соуси/олію/упаковку, не оновили після підвищення цін.
4. Нормальні діапазони фудкосту за типом закладу 🔎 (дати з авторитетного джерела або прибрати).
5. Як це робить ATOM: техкарти → собівартість у касі, склад з накладними (фото → ШІ), тривога «продаж нижче собівартості» (у планах — не обіцяти як готове).
6. Чек-лист на 5 пунктів. CTA.

## 2. QR-меню для кафе без комісії: що обирати
**Запит:** «QR меню для ресторану», «електронне меню безкоштовно».
**План:** навіщо QR (швидше замовлення, менше черг, апсейл); три моделі: лише перегляд меню / замовлення без оплати / замовлення з оплатою; на що дивитись (комісія, прив'язка до каси, мови, фото); як у ATOM — гість замовляє без додатків, замовлення одразу в касу й на кухню; безкоштовна демо-перевірка. Таблиця критеріїв без назв брендів.

## 3. ПРРО для кафе у 2026: що потрібно знати власнику
**Запит:** «ПРРО для кафе», «РРО ФОП 2026».
🔎 Усі правові твердження — лише з законодавства/ДПС/податкової консультації; статтю бажано вичитати бухгалтеру. Не писати «обов'язково/не обов'язково» без джерела.
**План:** що таке ПРРО; кому і коли потрібне (з посиланнями); програмне vs касовий апарат; скільки коштує фіскалізація (діапазон за офіційними тарифами, дата актуальності — напр., Checkbox ✅ 249–294 ₴, з 19.10.2026 348–393 ₴ за касу); як це поєднується з касою закладу; позиція ATOM: «інтеграція з Checkbox — у розробці» (уточнити перед публікацією).

## 4. Як відкрити кафе: що з техніки й програм
**Запит:** «що потрібно для відкриття кафе», «обладнання для кафе список».
**План:** чек-лист: планшет/телефон, чековий принтер, ПРРО, еквайринг, QR-меню, склад/облік, сайт з меню, доставка; що можна не купувати (дорога «залізна» каса); бюджет у вигляді діапазонів 🔎 або без цифр; як ATOM закриває більшість пунктів в одному місці. CTA на безкоштовне налаштування.

## 5. Як не втрачати гроші в закладі: 7 сигналів, що щось не так
**Запит:** «крадіжки в ресторані», «контроль офіціантів».
**План:** підозрілі знижки, видалені столи, перевідкриті чеки, нестача каси, часті відміни, списання без причини, розбіжності складу. Для кожного — що перевірити. Як ATOM показує такі сигнали власнику (тривоги в кабінеті). Тон: без звинувачень персоналу — про прозорі правила.

## 6. Лояльність для малого закладу без складних програм
**Запит:** «програма лояльності для кафе».
**План:** рівні постійних гостей за телефоном, щасливі години, «N-та кава в подарунок», день народження ±3 дні; як рахувати вигоду (не йти в мінус: стеля знижок); як налаштувати в ATOM (рівні, акції-правила, звіт про знижки). Реальний приклад з Varvar — після зняття цифр (див. кейс у marketing.md, п. 6).

## Метадані для кожної статті (запит Розробнику-2)
`<title>` ≤ 60 симв., `description` ≤ 155, один `h1`, ЧПУ латиницею (`/blog/foodcost`), OG-картинка, внутрішні посилання на демо й ціну, `lang="uk"`.
