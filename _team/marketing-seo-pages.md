# 🔎 SEO-сторінки під пошук (чернетки, не опубліковано)

Доповнює `marketing-seo.md` (статті). Тут — **посадкові сторінки під комерційні запити**. Правила: лише факти продукту (500 ₴/міс, перший місяць і налаштування 0 ₴, без договору на рік); ПРРО й онлайн-оплата — «у розробці»; Varvar, ціни конкурентів, лічильники — не називати до дозволу; без вигаданих відгуків і цифр. Частота запитів — 🔎 звірити в Google Keyword Planner / Search Console (я її не знаю).
Для кожної: URL · title (≤60) · description (≤155) · H1 · текст · FAQ-блок (для розмітки FAQPage) · внутрішні лінки. Один CTA: «Спробувати касу без реєстрації».

## Сторінка 1 — «POS для кафе»
**URL:** `/pos-dlya-kafe` · **Ключі:** pos система для кафе, програма для кафе, облік для кафе
**Title:** POS для кафе: каса, кухня і склад у телефоні | ATOM
**Description:** Українська POS-система для кафе: каса, QR-меню, кухня, склад і сайт в одному застосунку. 500 ₴/міс, перший місяць безкоштовно.
**H1:** POS-система для кафе, що працює з телефона
**Вступ (60 слів):** Для кафе не потрібен дорогий термінал і п'ять підписок. ATOM збирає касу, замовлення за QR, кухонний екран, склад і сайт у одному застосунку. Працює на телефоні чи планшеті, налаштування безкоштовне.
**H2 Що ви отримуєте** — список (каса й зал; QR-замовлення без додатків; кухня; склад і собівартість; постійні гості й акції; персонал і чайові; сайт; Telegram-боти).
**H2 Для кого** — «Кав'ярня, кафе-пекарня, фастфуд, бар до 30 столів».
**H2 Скільки коштує** — «500 ₴ на місяць за заклад. Перший місяць і налаштування безкоштовні. Договору на рік немає.»
**H2 Старт за 3 кроки** — надіслали меню → налаштували принтер, боти, сайт → навчили команду.
**H2 Чесно про межі** — «ПРРО й онлайн-оплата в розробці. Обладнання не входить у підписку.»
**FAQ:** Чи потрібен спеціальний термінал? (ні, телефон/планшет, принтер за потреби) · Скільки часу займе запуск? (🔎 зазвичай день, підтвердити) · Чи можна перенести меню? (так, таблицею) · Чи можна спробувати без реєстрації? (так).
**Лінки:** `/qr-menyu`, `/kasa-dlya-restoranu`, блог «Фудкост».

## Сторінка 2 — «Каса для ресторану»
**URL:** `/kasa-dlya-restoranu` · **Ключі:** каса для ресторану, програма для ресторану, облік ресторану
**Title:** Каса для ресторану: зал, кухня, склад, доставка | ATOM
**Description:** Каса для ресторану в одному застосунку: столи, поділ чека, кухня, склад із собівартістю, доставка й броні. 500 ₴/міс.
**H1:** Каса для ресторану: зал, кухня, склад і доставка разом
**Вступ:** Офіціант відкриває стіл, кухня бачить замовлення одразу, власник — виручку й собівартість у кабінеті. Без окремих програм для складу, зарплати й сайту.
**H2 Зал і столи** — карта столів, поділ чека (по позиціях і порівну), знижки, чайові.
**H2 Кухня** — екран замовлень, «готово» повертається офіціанту.
**H2 Склад і собівартість** — техкарти, накладні з фото (ШІ), інвентаризація.

**H2 Ціна** — як у сторінці 1.
**H2 Чесно про межі** — ПРРО/оплата у розробці; для мереж 5+ точок — 🔎 уточнити формат.
**FAQ:** Чи можна кілька закладів? (мережа — 🔎 умови) · Як контролювати персонал? (журнал, права ролей) · Чи працює без інтернету? (🔎 уточнити стан офлайн-режиму) · Хто навчатиме команду? (курс усередині каси).
