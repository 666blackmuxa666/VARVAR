# 🏪 Платформа: багато закладів, кабінет власника (етап 1 — 2026-10-06)

## Як влаштовано
- **Один воркер, окремий Durable Object `Store` на заклад.** VARVAR = заклад `varvar` = DO «main» (дані не переносились, старі адреси працюють).
- **Адреса закладу:** префікс `/v/<id>/…` (каса `pos.html?v=<id>`, сайт `index.html?v=<id>` / `about.html?v=<id>`, вебхуки `/v/<id>/tg|tg2|tg3`, картинки `/v/<id>/img/…`). Без префікса — VARVAR.
- **`worker/src/venue.js`:** `splitVenue`, `doName`, контекст запиту `ALS` (AsyncLocalStorage, `compatibility_flags = ["nodejs_als"]`): `venueId()`, межа дня `cur().dayH` (НЕ глобальна змінна!). `venueEnv` — env закладу: секрети з `cfg:secrets` (AES-GCM, `MASTER_KEY`), свій `SELF_URL`, свій `TG_SECRET` (HMAC), без секретів VARVAR (ADMIN_PIN = ''). `siteLink(path)` — посилання на сайт з `?v=`.
- **`worker/src/hub.js` — DO `Hub`** (один): `acct:<email>` (PBKDF2), `venue:<id>`, `sess:<token>` 30 дн, `seen:<id>`, блок після 8 невдалих входів на 15 хв. RPC-методи.
- **`worker/src/owner.js`:** `/api/owner` (login, bootstrap, me, sum, enter, codes, secrets, pass; платформа: accts, acctNew, acctPass, venueNew, venueSet) + внутрішні `/__int/*` у закладі (заголовок `x-int` = HMAC(MASTER_KEY)): init (випадкові коди реєстрації, порожнє меню, нейтральна візитка, PRINT_KEY), login (сесія адміна «👑 Ім'я» без PIN), whoami, sum (цифри з `reportRange` + «зараз»), codes, secrets (перевірка токенів getMe, вебхук бота персоналу).
- **Store:** заклад без `cfg:venue` → 404 (крім init). Нові DO НЕ копіюють KV (стара міграція — лише для main).
- **Група персоналу нового закладу** підключається сама: перша група, куди додали бота персоналу (`index.js /tg`).
- **Cron** обходить VARVAR + активні заклади з HUB.
- **Картинки** у спільному KV: `img:<заклад>/…` (VARVAR — `img:…`).
- **Фронт:** `owner.html` + `js/owner.js` + `css/owner.css`. Каса: `VENUE` у `00-core.js` (з `?v=`, пам'ятається на пристрої; `?v=varvar` — повернутись до VARVAR), сховище `pos_<заклад>_*`, вхід з кабінету `#tok=…&me=…`. Сайт: `js/config.js` (`C.venue`, `C.pre`, `C.link`).
